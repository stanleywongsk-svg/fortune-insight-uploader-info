私隱政策

生效日期：2026 年 9 月 29 日

本政策適用於 Fortune Insight Uploader 的 Google／YouTube 授權、上載及排程功能，包括整合於 All in One 的相應流程。聯絡電郵：insightfortune@gmail.com。

1. 處理哪些資料

  • Google 發出的 OAuth 存取及續期憑證；不收集 Google 密碼。
  • 已授權頻道的 ID、名稱、上載播放清單及相關影片的 ID、標題、描述、縮圖、處理狀態、隱私狀態與公開時間。
  • 操作人員指定的影片、縮圖、標題及描述，以及本機工作日誌、檔案雜湊和上載結果。
  • 若另外啟用 Google Drive 備份，處理指定備份檔案、目的資料夾及上載結果。

2. 用途及分享

資料用於核對頻道、完成操作人員要求的上載、更新縮圖和影片設定、安排公開時間、檢查處理結果及防止重複上載。影片與相關資料會按指定設定傳送給 Google／YouTube；啟用 Drive 備份時，指定檔案會傳送至 Google Drive。

本工具不以出售 Google 使用者資料、廣告定向或訓練通用 AI 模型為目的處理上述資料。影片製作流程如使用另外的 AI 或素材服務，操作人員輸入的文稿及素材可能交由相關服務處理；本政策不取代那些服務的私隱政策。

3. 儲存及保留

授權憑證及工作紀錄保存於執行工具的電腦。憑證用於自動續期，直到被替換、刪除、撤銷或失效。上載帳本及相關日誌由管理人員保留以支援恢復及防止重複上載，應在不再需要時刪除；不應把憑證放入公開網站或程式碼庫。

已上載至 Google 的影片及檔案按其帳戶設定保留。工具的低磁碟清理功能只在符合上載確認及檔案核對條件時刪除本機影片，不會因此刪除 YouTube 影片。

4. 撤銷授權及刪除資料

你可隨時在 Google 帳戶權限設定撤銷此工具的存取權，或聯絡管理人員停止工作並移除本機憑證和相關紀錄。撤銷授權本身不會刪除已上載的影片、Drive 檔案或本機紀錄；遠端內容可在 YouTube Studio 或 Google Drive 管理。

如需查詢或提出資料刪除要求，請聯絡 insightfortune@gmail.com，並指出相關頻道或工作；請勿在郵件中提供密碼或授權憑證。

5. 公開網頁及 Google 政策

這兩個說明頁本身沒有登入表單、廣告或分析追蹤程式，也不接收上載影片或 OAuth 回呼。託管服務可能為提供網頁及安全防護而記錄 IP 位址及請求資料；本說明網站由 GitHub Pages 託管，請參閱 GitHub 私隱聲明。

Google／YouTube 對資料的處理亦受 Google 私隱權政策規範。本工具對 Google API 資料的使用及轉移須遵守 Google API Services User Data Policy，包括適用的 Limited Use 要求。

6. 政策更新

資料用途或功能改變時會更新本頁及生效日期。
